# Agenda De Eventos Interna

Agenda corporativa interna para eventos operativos, de seguridad y coordinacion entre plantas y equipos de infraestructura.

## Uso

1. `npm install`
2. `npm run dev`

Incluye filtros, destacados, detalle completo de eventos y registro persistente en `localStorage`.
## Modos de uso

- Desarrollo: `npm install && npm run dev`
- Archivo estatico: ejecuta `npm run build` y abre `index.html` en la raiz del proyecto.
